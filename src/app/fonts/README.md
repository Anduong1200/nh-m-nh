# Display font

Unmodified Lora variable font, weight 400–700, from the [Google Fonts source repository](https://github.com/google/fonts/tree/main/ofl/lora). This file includes the Vietnamese character set. The accompanying `OFL.txt` preserves its copyright and SIL Open Font License 1.1.

`next/font/local` serves it from same-origin immutable build assets. Browsers make no request to a third-party font service. Headings use `--font-display`; body text keeps the system UI font. The existing service worker can cache the public immutable font asset along with other build files.
