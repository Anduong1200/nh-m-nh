# games

Async-first domain for Doodle Relay, Draw & Guess, One-line Story and Photo Mission. Generic sessions/players/turns/events/artifacts, authenticated actions, transactional RPC/RLS, immutable retry receipts and account-bound offline drafts/queues are implemented. Read [Games domain / UI handoff](../../../docs/GAMES_DOMAIN.md) for contracts, schema, integration and verification boundaries. No XP or leaderboards.

Canonical requirements: `PRODUCT_SPEC.md`, `docs/ARCHITECTURE.md`, `docs/SECURITY.md` and `AGENTS.md`.
