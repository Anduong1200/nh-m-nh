# island

Own Shared Island event contracts, derived world state, and the user-confirmed
Memory/Milestone journal. Progress follows trusted persisted sources without
currency, decay or absence penalties. Both members edit pages; creators alone
trash/restore. Version conflicts and immutable retries preserve partner content.
See [Island domain](../../../docs/ISLAND_DOMAIN.md) for persistence, authorization,
offline draft/cache behavior, installation and verification limits.

Canonical requirements: `PRODUCT_SPEC.md`, `docs/ARCHITECTURE.md`, `docs/SECURITY.md` and `AGENTS.md`.
