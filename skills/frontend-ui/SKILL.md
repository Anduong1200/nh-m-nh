# Frontend/UI Skill

## Visual identity

- cozy
- adventurous
- cute
- scout
- weird
- playful
- scrapbook
- hand-drawn
- field notebook
- adaptive day/night
- cream/forest/brown foundation
- motion 3/5

## Layout principle

Home should feel spatial, not like an analytics dashboard.

Desktop:
- first-class;
- exploit space for room/island/board interactions.

Mobile:
- preserve direct touch access;
- avoid tiny draggable targets;
- collapse secondary controls.

## Accessibility

Implement:
- semantic controls;
- keyboard navigation;
- visible focus;
- reduced motion;
- ARIA labels where necessary;
- strong enough contrast;
- non-color-only status meaning.

## Component policy

Prefer:
- reusable primitives;
- accessible dialogs;
- explicit state machines for complex interaction.

Avoid:
- overabstracting before repeated use;
- decorative complexity that harms input reliability.

## Empty/error states

Use mascots sparingly.
Never shame the user.

Good:
- “Chưa có gì ở đây. Để lại thứ đầu tiên?”

Bad:
- “Hai bạn chưa tương tác hôm nay.”
