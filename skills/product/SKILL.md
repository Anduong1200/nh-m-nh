# Nhà Mình Product Skill

## Use when

Use this skill when:
- defining a new flow;
- changing product behavior;
- writing user stories;
- reviewing scope;
- deciding whether a feature belongs in V1.

## Product test

A change should support at least one:
- Presence
- Play
- Understanding
- Memory
- Shared World

Ask:

1. Does this make the app feel more like a private home/world for two?
2. Does it duplicate Locket?
3. Does it accidentally become chat/social media/productivity tooling?
4. Does it pressure daily engagement?
5. Can it work async?
6. Can a user enjoy it in a 5–10 minute session?

## Reject or defer

Reject/defer:
- follower/public features;
- streak penalties;
- relationship scores;
- surveillance;
- XP grind;
- unrelated mini-games;
- generic engagement hacks;
- V1 scope expansion without approval.
