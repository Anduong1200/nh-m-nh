# Design System Direction

## Mood

- cozy
- adventurous
- cute
- scout
- weird
- playful

## Base palette direction

Adaptive day/night.

Day base:
- warm cream/paper
- forest green
- brown/wood
- restrained accent colors

Night:
- dark warm neutral
- muted forest
- soft lamp/fire highlights

Do not hardcode exact palette until UI prototypes are reviewed.

## Surfaces

Preferred metaphors:
- paper
- cork
- notebook
- wood
- map
- fabric/patch

Avoid heavy skeuomorphism that harms usability.

## Typography

Use a highly readable body font.
Handwritten/decorative font may be used sparingly for:
- labels;
- notes;
- headings;
- playful artifacts.

Never use decorative handwriting for long body text.

## Motion

Level 3/5.

Good:
- lamp on/off;
- mascot reaction;
- card/paper placement;
- subtle weather/window changes;
- island object appearing.

Respect `prefers-reduced-motion`.

## Mascots

- rabbit
- owl

They may:
- move subtly;
- react to events;
- appear in empty states;
- create playful microinteractions.

They must not:
- demand care;
- become sad due to inactivity;
- create guilt.

## Scout motifs

Use sparingly:
- patches;
- map symbols;
- trail signs;
- camp objects;
- field notebook language.

Keep overall product modern and intimate.
