# UX Rules

## Emotional safety

The app must invite, not demand.

Never use copy implying:
- neglect;
- failure;
- abandonment;
- “relationship health decline”;
- streak loss;
- obligation to reply.

## Session design

Healthy session:
- 5–10 minutes.

A user should be able to:
- enter;
- see something from partner;
- respond/play;
- leave.

No infinite feed.

## Presence

Explicit and temporary.

Do not infer:
- mood from activity;
- relationship state from response time;
- availability from online status.

## Async-first

Good async examples:
- partner leaves doodle;
- user continues it hours later;
- one-line story turn;
- photo mission;
- scheduled letter.

Do not require simultaneous presence for core value.

## Cute vs childish

Allowed:
- mascots;
- subtle animations;
- handwritten elements;
- playful objects;
- weird jokes.

Avoid:
- excessive baby language;
- overuse of hearts;
- juvenile reward systems;
- childish UI that undermines emotional depth.

## Shared room

Home should feel spatial and lived-in.

Avoid:
- dashboard cards everywhere;
- admin-panel aesthetics;
- productivity KPIs.

## Board

Embrace controlled messiness:
- moveable notes;
- rotation;
- overlapping objects;
- varied media.

Still preserve:
- keyboard accessibility where practical;
- readable contrast;
- predictable editing controls.

## Games

Games should:
- be short;
- be personal;
- work async;
- create a shared artifact;
- allow custom prompts.

Games should not:
- dominate the app;
- become competitive pressure;
- create XP grind.

## Island

Island should reward history, not frequency.

No:
- decay;
- currency;
- loss for absence.

## Faith / reflection

Prayer, Mother Mary imagery, “phút hồi tâm”, intentions:
- respectful;
- optional;
- private;
- not scored;
- not tracked as compliance.

## Notifications

Default lock-screen copy:
- generic.

User may opt into richer content.

Quiet hours:
- per user.

## Accessibility

Target WCAG 2.2 AA where practical.

Must account for:
- reduced motion;
- keyboard navigation on desktop;
- contrast;
- focus states;
- semantic labels;
- touch targets;
- non-color-only meaning.
